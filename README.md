## Descripción del Proyecto

Este repositorio contiene el desarrollo de las dos fases del laboratorio de programación asistida por LLMs. El objetivo principal es aplicar una metodología rigurosa para el desarrollo, validación y comprobación de código utilizando herramientas de Inteligencia Artificial.

### FASE 1: Creación de Preguntas y Generadores
En esta fase se plantearon 4 ejercicios originales relacionados con el análisis de datos y machine learning (utilizando `pandas`, `numpy` y `sklearn`).
- **Ubicación:** Carpeta `myquestions/`
- **Contenido:** Enunciados (`question-XXXX.txt`) y scripts generadores de casos de uso aleatorios (`question-XXXX-usecase-generator.py`).

### FASE 2: Solución de Retos Asignados
En esta fase se desarrollaron las soluciones para 4 problemas diseñados por compañeros del curso. Cada solución fue validada contra los generadores de casos de uso correspondientes para asegurar la exactitud del resultado.
- **Ubicación:** Carpeta `myanswers/`
- **Contenido:** Funciones de solución nombradas estrictamente según el ID asignado (`answer-XXXX.py`).
